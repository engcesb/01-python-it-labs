# 01-python-it-labs
Laboratórios, scripts de automação e utilitários em Python para infraestrutura de TI, scraping e manipulação de dados.

### Repositório focado na automação de processos operacionais e administrativas de TI utilizando Python. Reúne scripts para scraping de dados, automação de tarefas do sistema operacional, manipulação de arquivos estruturados e utilitários de suporte a ambientes corporativos e acadêmicos. Serve como fundação para testes rápidos de algoritmos e rotinas de backend.
